# Yes or No Logic Quiz

A small Python desktop quiz with six classic logic-puzzle scenes. The game uses a simple Tkinter window and displays one question image at a time.

## Run on Windows

1. Install Python 3.
2. Open a terminal in this project folder.
3. Install the dependency:

   ```powershell
   py -m pip install -r requirements.txt
   ```

4. Start the game:

   ```powershell
   py main.py
   ```

On macOS or Linux, replace `py` with `python3`.

## Included questions

The `questions` folder contains the six PNGs used by the game. Correct answers are configured in the `QUESTIONS` list in `main.py`.
